Privacy Policy for CleanSnap

Effective Date: October 2026

Summary: CleanSnap collects zero user data. All photo and video processing (EXIF stripping, GPS coordinate removal, and metadata scrubbing) takes place entirely on your device. Nothing is uploaded to any server or cloud service.

1. Zero Data Collection

CleanSnap does not collect, store, sell, or transmit any personal data, identifiers, device information, or media files. We have no user accounts, no analytics SDKs, and no tracking cookies.

2. Media & Local Processing

When you select or drop photos and videos into CleanSnap:

  • Processing is performed 100% locally on your device hardware (CPU/GPU).
  • Cleaned media is saved directly to your local file system (e.g., Pictures/Cleaned_Media and Movies/Cleaned_Media).
  • No internet connection is required or used during media processing.

3. Device Permissions

On Android, CleanSnap uses the standard system Photo Picker and scoped MediaStore storage APIs. The app only accesses files explicitly chosen by you and does not request broad file system access.

4. Third-Party Services

CleanSnap does not integrate third-party advertising networks, analytics providers, or behavioral trackers.

5. Children's Privacy

Because CleanSnap does not collect any personal information whatsoever, it is fully compliant with COPPA and GDPR regulations.

6. Open Source & Transparency

CleanSnap's source code is publicly verifiable on GitHub at github.com/bonikaeu-svg/CleanSnap.
